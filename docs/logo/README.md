# gtellcorr logo

Concept: starlight passing through layered atmosphere (lower + upper profiles),
the beam thinning at each layer as it is absorbed before reaching the ground.

| File | Use |
|---|---|
| `gtellcorr-logo.svg` / `.png` | Horizontal lockup on light backgrounds (README header, docs) |
| `gtellcorr-logo-dark.svg` / `.png` | Horizontal lockup on dark backgrounds |
| `gtellcorr-mark.svg`, `gtellcorr-mark-512.png`, `gtellcorr-mark-1024.png` | Icon alone, 48 px and larger (avatar, Zenodo, slides) |
| `gtellcorr-mark-small.svg`, `favicon-*.png`, `favicon.ico` | Simplified icon for 16–48 px |
| `apple-touch-icon.png` | 180 px touch icon for the docs site |
| `gtellcorr-wordmark.svg` | Wordmark only |

Text is outlined (IBM Plex Mono SemiBold, SIL OFL), so no font install is needed.

Colours: ink `#0F1E2E`, tile `#F8FAFC`, accent `#3D86D6`, light text `#F4F7FA`.

README usage:

```html
<p align="center"><img src="docs/logo/gtellcorr-logo.svg" alt="gtellcorr" width="420"></p>
```
